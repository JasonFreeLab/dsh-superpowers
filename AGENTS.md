# AGENTS.md

This repository is a DSH plugin that ports the obra/superpowers skills.

- Skill content is English (i18n); only README.md and README.zh.md may contain Chinese.
- Skill names use the `superpower-` prefix; cross-references use `superpower-<name>`.
- Claude Code tools are mapped to DSH tools (see `skills/superpower-using-superpowers/references/dsh-tools.md`).
- Run `npm run build && npm test && npm run verify` before committing.
